GPS Viewer v13 fixes

- Uses /api/reverse directly.
- Corrected a response-contract bug: the Worker returns the location object directly,

  Pages can read the cross-origin JSON response.
- Post Office is obtained from the Worker response; the Worker performs the PIN lookup
  server-side, avoiding browser CORS dependence on the postal API.
